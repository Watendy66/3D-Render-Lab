# 3D 变换与渲染实验 (Taichi 实现)

这是一个基于 **Taichi Lang** 编写的 3D 线框渲染程序。它模拟了现代图形学管线中的核心步骤：**MVP 变换**、**透视除法**以及**视口变换**。

## 项目概览

本项目实现了一个可以在 3D 空间中旋转的彩色三角形。通过键盘实时控制旋转，直观地展示 3D 坐标如何映射到 2D 屏幕。

## 核心功能

1.**实时变换**：通过矩阵运算实现物体的旋转、平移和投影。
2.**三色渲染**：为三角形的三条边（Red, Green, Blue）独立着色。
3.**交互控制**：支持 `A` / `D` 键控制旋转，`ESC` 退出。

## 🛠 渲染原理
### 1. 坐标系转换 (MVP Transformation)
每个顶点经历以下变换：
- **Model (M)**: 局部空间 → 世界空间（实现绕 Z 轴旋转）。
- **View (V)**: 世界空间 → 相机空间（模拟相机在 $Z=5$ 处观察）。
- **Projection (P)**: 相机空间 → 裁剪空间（实现“远小近大”）。

### 2. 关键数学步骤
- **透视除法 (Perspective Division)**:
  $$v\_{ndc} = \frac{v\_{clip}.xyz}{v\_{clip}.w}$$
  将坐标归一化到 $\[-1, 1]$ 的 NDC 空间。
- **视口变换 (Viewport Transform)**:
  将 $\[-1, 1]$ 映射到 $\[0, 1]$ 范围，适配 Taichi Canvas 坐标系。

## 🚀 进阶实现：

相比基础的三角形旋转，立方体版本通过定义 8 个顶点构造成标准单位立方体，并利用 **三角形索引（Triangle Indices）** 技术，将顶点重用并重组为 12 个三角形面片（每面 2 个），实现了顶点数据的复用，仅需对 8 个原始顶点进行 MVP 变换，即可通过 `face_indices` 引导 GPU 高效渲染出 6 个封闭的实体表面。并且通过复合旋转矩阵（$M = M_y \cdot M_x$），支持 `W/S/A/D` 四键实时控制立方体绕多轴旋转，展示了更加复杂的世界坐标变换逻辑，还引入了线性插值（Lerp）或正弦插值概念，使立方体在不同姿态切换时具备物理惯性般的视觉平滑感。
不仅如此还采用了简单的平行光的模型，通过 **逐面亮度偏移（Face-id Shading）** 实现了立方体表面细腻的光照效果，还引入了 **兰伯特余弦定律** 和 **体积感增强** 等高级技术，进一步提升了立方体的视觉效果。
  * **兰伯特余弦定律 (Lambert's Law)**：引入了\*\*面法线（Normal）\*\*概念。通过计算变换后的法线与全局光照方向的点积（$\text{max}(0.1, \vec{n} \cdot \vec{l})$），实时确定各表面的明暗程度。
  * **体积感增强**：配合逐面亮度偏移（Face-id Shading），在无需复杂纹理的情况下，利用明暗对比（Chiaroscuro）极大增强了 3D 几何体的空间体积感。
